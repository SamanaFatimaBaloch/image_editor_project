This project is a browser-based Image Editor built using HTML, CSS, and Vanilla JavaScript. It allows users to upload an image from their device, apply various filters in real time, and download the edited image. The application uses the HTML Canvas element to display and manipulate images, where all filter effects like brightness, contrast, saturation, blur, grayscale, and more are applied dynamically through JavaScript. A filters object is used to manage values, ranges, and units, while sliders are generated dynamically for user interaction. The project also includes predefined filter presets such as Noir, Vintage, Drama, and Faded, which apply multiple effects at once for quick editing. Users can reset all filters to default values and instantly see changes reflected on the canvas. Overall, this project demonstrates the power of core web technologies, focusing on real-time image processing, dynamic UI creation, and effective use of JavaScript without relying on external libraries or frameworks.
